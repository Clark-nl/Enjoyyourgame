# 마블 룰렛+ 🎱

시드 기반으로 **재현·검증 가능한** 공정한 구슬 굴리기 추첨기.

▶ **라이브:** https://clark-nl.github.io/Enjoyyourgame/

- 이름 입력(쉼표/줄바꿈, `이름*3` = 구슬 3개), 셔플, CSV 붙여넣기
- 1등 / 꼴등 / N명 당첨 / 팀 나누기
- 맵 5종 (핀볼, 지그재그, 회전 풍차, 대혼전, 플링코) — `index.html` 안의 JSON으로 추가 가능
- 시드 + 고정 타임스텝 물리 → 결과 링크로 누구나 재생·검증
- 슬로모션 카메라, 실시간 순위, 컨페티, 효과음, WebM 녹화, 스트리머(크로마키) 모드
- 단축키: `Space` 시작 · `M` 음소거 · `S` 스트리머 · `1/2/3` 속도

☕ 응원하기: https://ko-fi.com/clarkpark
